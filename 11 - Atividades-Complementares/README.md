# 🎓 Atividades Complementares

Para concluir a graduação em Engenharia de Computação, a UNIVESP exige o cumprimento de uma carga horária mínima de atividades complementares extracurriculares (palestras, congressos, cursos livres, etc.). 

Use esta tabela para organizar suas horas e guardar seus comprovantes.

---

## 📊 Resumo das Horas
* **Horas Obrigatórias**: 200 horas (a confirmar no PPC do ano vigente)
* **Horas Concluídas**: 0 horas
* **Horas Restantes**: 200 horas

---

## 🗂️ Registro de Certificados

| Atividade / Evento | Instituição | Carga Horária | Comprovante (Caminho do PDF) | Status |
|--------------------|-------------|:---:|:---:|:---:|
| Exemplo: Curso de Git e GitHub | Alura / Coursera | 20h | `[cert_git.pdf](./certificados/cert_git.pdf)` | `Aprovado` |
| | | | | |

---

## 📌 Orientações para Envio (Portal do Aluno SEI)
1. Salve todos os certificados em formato PDF na subpasta `certificados/` que você pode criar aqui dentro.
2. Acesse o **Portal do Aluno (SEI)** -> menu **Protocolos** -> **Nova Solicitação** -> selecionar a opção de envio de horas complementares.
3. Preencha a descrição, anexe o comprovante e registre o número do protocolo na tabela acima.
