# COM170 — Disciplina Regular (IA na Prática Acadêmica e Profissional)

> **Carga Horária:** 80h | **Duração:** 8 Quinzenas (2 semanas por quinzena)  
> **Início Oficial:** Segunda-feira, **20/07/2026**

---

## 🧭 Como Funciona a Disciplina (Modelo Oficial UNIVESP)

Cada Quinzena tem a duração de **2 semanas** e é estruturada rigorosamente em **7 Módulos**:

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  SEMANA 1 — BASE INDIVIDUAL (Módulos 1 a 4)                      │
 │  • M1: Leitura e Estudo de Fundamentos                           │
 │  • M2: Videoaulas e Aplicação Prática                            │
 │  • M3: Quizzes e Testes de Conhecimento                          │
 │  • M4: Atividade Individual (⭐ PRAZO FIXO: 1º Domingo às 23h59)  │
 └──────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
 ┌──────────────────────────────────────────────────────────────────┐
 │  SEMANA 2 — LABORATÓRIO E FASE COLETIVA (Módulos 5 a 7)          │
 │  • M5: O Problema da Quinzena (Instruções) — Abre para todos     │
 │  • M6: Portfólio Individual (Reflexão do Aprendizado)            │
 │  • M7: Trabalho em Grupo (🤝 EXCLUSIVO para quem cumpriu o M4)   │
 └──────────────────────────────────────────────────────────────────┘
```

> 🚨 **Regra do Módulo 4 (Gargalo de Acesso ao Grupo):**  
> - Se você entregar o Módulo 4 até a data limite (**1º domingo da quinzena às 23h59**): Abrem M5, M6 e **M7 (Grupo)**.  
> - Se perder o prazo do Módulo 4: Abrem M5 e M6 (Portfólio Individual), mas o **M7 (Grupo) fica bloqueado** para aquela quinzena. Na quinzena seguinte, entregando o M4 no prazo, você volta ao grupo normalmente!
